🔥 ตั้งค่า Firebase

Firebase ทำให้ข้อมูลอยู่บน Cloud — ใช้ได้ทุก device ไม่หายแม้ล้าง browser

1
สร้าง Firebase Project
ไปที่ console.firebase.google.com → Add project → ตั้งชื่อ
2
เพิ่ม Web App
Project Settings → Add app → Web (🌐) → ได้ firebaseConfig
3
เปิด Authentication + Firestore
Authentication → Sign-in method → เปิด Google | Firestore Database → Create database → Start in test mode
4
วาง Config ด้านล่าง
คัดลอก firebaseConfig จากหน้า Project Settings แล้ววางตรงนี้
🔒 ปลอดภัย
Config เก็บในเครื่องคุณเท่านั้น ไม่ได้ส่งไปที่อื่น | ข้อมูลเข้าถึงได้เฉพาะบัญชี Google ของคุณ
